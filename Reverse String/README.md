# 344. Reverse String

## 📌 Problem Statement

Given an array of characters `s`, reverse the array **in-place**.

The input is provided as an array of characters, and the original array must be modified directly without using additional memory proportional to the input size.

---

## 📝 Examples

### Example 1

**Input**
```text
s = ["h","e","l","l","o"]
```

**Output**
```text
["o","l","l","e","h"]
```

### Example 2

**Input**
```text
s = ["H","a","n","n","a","h"]
```

**Output**
```text
["h","a","n","n","a","H"]
```

---

## 📋 Constraints

- `1 <= s.length <= 10^5`
- `s[i]` is a printable ASCII character.

---

## 🎯 Objective

Reverse the given character array by modifying the original array directly.


---


## ⏱ Expected Complexity

| Complexity | Value |
|------------|-------|
| Time | `O(n)` |
| Space | `O(1)` |
